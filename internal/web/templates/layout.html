What do these statuses mean?

MCP tool calls: a tool request reached this server. This can be OK even when the Jira operation fails; it does not track whether a client remains connected.

LLM provider: the configured language-model service used for fallback translation and AI features. This records the last observed model-backed operation, including output errors. Deterministic queries may never contact it.

Unknown means no operation has been observed. Stale means the last observation is over five minutes old. OK or failed describes the last observed operation. These are observations, not continuous connection tests; an unused provider can leave readiness unknown.

Checks Jira connectivity and authentication only; project permissions are not checked.
